# Non-Production Boundary

This demo is a development artifact for architecture discussion and SDK
validation.

It is not:

- a production compliance system
- a bank-approved workflow
- a vendor-certified integration
- a substitute for legal, regulatory, audit, or model-risk review

The current signer is `L0SoftwareDev`. Production usage would require a
stronger signer, key management, operational controls, and formal verification
requirements.
