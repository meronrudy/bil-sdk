# Design-Partner Questions

- Which workflow stages most often lose audit context across vendor boundaries?
- Which events should become mandatory receipt inputs?
- Which evidence hashes should be retained by the bank, the vendor, or both?
- What signer assurance level would be acceptable for a pilot?
- What does the bank need the verifier report to say in an examiner-ready packet?
- Which policy references should be stable identifiers versus human-readable labels?
- Which replay checks would make this useful for internal audit?
