# Insurance

`Insurance/AiSSURANCE` is the only supported in-repo insurance subtree.

It is a local downstream of the public BIL workspace and integrates through the
feature-gated bridge in `integrations/bil-aissurance-bridge`.

For repo-wide support tiers and LOC reality, see
[../docs/repo-assessment.md](../docs/repo-assessment.md). For the downstream
integration flow, see
[../docs/aissurance-local-integration.md](../docs/aissurance-local-integration.md).
