# Experiments

`experiments/` holds live standalone work that is intentionally outside the
root BIL workspace.

The current experiment is `axiom-tui`, an operator-facing Rust TUI prototype
that builds and tests independently from the root workspace.

These paths are active, but they are not part of the default public-core
guarantees. See [../docs/repo-assessment.md](../docs/repo-assessment.md) for
repo-wide support tiers.
